# CITA-314-FinalProject
Capstone Project for Mixed Reality Class

CITA 314 - Special Temple

You find yourself in a special temple that is connected to multiple realms. By solving a simple puzzle you're able to access these realms.

The chosen platform for this project is VR.

You can run the project by taking the build file, exporting it to your Meta Quest or other VR device, and then running the file from your device.

Interactive Objects:
Coins, Fountains, UI, Fishing Rod, Fish. You're able to spawn and remove objects using these interactables.
